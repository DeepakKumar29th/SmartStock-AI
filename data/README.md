# SmartStock AI — Supply & Inventory Datasets

Raw and processed training datasets are excluded from Git version control due to file size constraints (> 1 GB).

## Primary Supply & Inventory Dataset (FreshRetailNet-50K)
- **Source:** Dingdong Inc. / Hugging Face
- **URL:** https://huggingface.co/datasets/Dingdong-Inc/FreshRetailNet-50K
- **Paper:** [arXiv:2505.16319](https://arxiv.org/abs/2505.16319)
- **Scope:** 4.5 million records across 898 stores, 865 SKUs, 90 continuous days (March–June 2024).

Place raw dataset files in data/raw/ and generated ML feature tables in data/processed/.
